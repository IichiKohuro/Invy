# Фаза 0: ручная проверка на Windows и Android

Автоматические тесты и сборка проверены в Linux-окружении. Ниже — то, что можно проверить только на реальной Windows и на телефоне. Отметьте результат: ✅ / ❌ + заметка.

Подготовка (Windows, PowerShell, корень репозитория):

```powershell
dotnet restore
$env:AVALONIA_TELEMETRY_OPTOUT = '1'   # необязательно: отключает сбор статистики сборки Avalonia
```

## 4. Обновление Desktop через Velopack — [ADR 0004](../../adr/0004-desktop-updates-velopack.md)

Сервер из п. 3 запущен; dev-сервер хранит данные в `.data\server`.

```powershell
./tools/pack-desktop.ps1 -Version 0.1.1 -ReleasesDir .data/server/releases/win
& .data/server/releases/win/Invy.Desktop-win-Setup.exe
./tools/pack-desktop.ps1 -Version 0.1.2 -ReleasesDir .data/server/releases/win
```

| # | Проверка | Результат |
|---|----------|-----------|
| 4.1 | `Setup.exe` ставит приложение без прав администратора (SmartScreen: «Подробнее» → «Выполнить в любом случае») | |
| 4.2 | Установленное приложение: Настройки → Обновления показывает «Установлена версия 0.1.1» | |
| 4.3 | «Проверить» → «Версия 0.1.2 загружена…» → «Установить» → приложение перезапускается, версия 0.1.2 | |
| 4.4 | Для 0.1.3: «Проверить обновления» в трее, затем «Выход» — при следующем запуске версия 0.1.3 (установка при выходе) | |
| 4.5 | Сервер выключен → «Проверить» показывает понятную ошибку, приложение работает дальше | |

## 5. Android — [ADR 0005](../../adr/0005-android-host-and-apk-updates.md)

Нужен Android SDK (ставится с Visual Studio или Rider) и телефон в той же Wi-Fi-сети. Разрешите входящие подключения к серверу:

```powershell
New-NetFirewallRule -DisplayName 'Invy Server (dev)' -Direction Inbound -Protocol TCP -LocalPort 5470 -Profile Private -Action Allow
```

```powershell
./tools/pack-android.ps1 -Version 0.1.1 -ReleasesDir .data/server/releases/android
```

На телефоне откройте `http://<IP-адрес-ПК>:5470/updates/android/invy-0.1.1.apk`, установите APK.

| # | Проверка | Результат |
|---|----------|-----------|
| 5.1 | Приложение запускается; меню сворачивается в «гамбургер»; кириллица и иконки на месте | |
| 5.2 | Тёмная тема телефона → тёмная тема Invy | |
| 5.3 | Настройки → «Сервер Invy»: ввести IP ПК; «Проверить» → «Установлена последняя версия (0.1.1)» | |
| 5.4 | Выпустить `-Version 0.1.2`; «Проверить» → «Установить» → в первый раз Android просит разрешить установку из Invy → разрешить, нажать «Установить» ещё раз → системное подтверждение → версия 0.1.2 | |
| 5.5 | Выпустить `-Version 0.1.3`; «Установить» на Android 12+ — **без** системного подтверждения (Invy теперь источник установки) | |
| 5.6 | Неверный адрес сервера → понятная ошибка, приложение не падает | |
