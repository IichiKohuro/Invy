# 0003. Desktop: трей, глобальные горячие клавиши, один экземпляр

**Статус:** Принято с оговорками (спайк фазы 0, 2026-11-04) — работа трея и `RegisterHotKey` на Windows проверяется вручную, см. [чек-лист](../spikes/phase-0/checklist.md)

## Контекст

Desktop-приложение живёт в трее, открывает быстрый поиск по глобальной горячей клавише и не должно запускаться дважды: автозапуск, ярлык и `Invy.Desktop.exe --search …` обязаны попадать в уже работающий экземпляр.

## Решение

1. **Точка расширения `IAppHost`** (Client.UI): `App` создаётся через `AppBuilder.Configure(() => new App(host))`, хост сам решает, какие окна показать. Android будет использовать тот же механизм.
2. **`DesktopHost`**:
   - `ShutdownMode = OnExplicitShutdown`: закрытие главного окна только скрывает его, выход — из меню трея;
   - трей — встроенный `Avalonia.Controls.TrayIcon` + `NativeMenu` (Найти… · Добавить вещь… · Открыть Invy · статус сервера · Выход), левый клик — быстрый поиск;
   - `--background` — старт только в трей (для автозапуска).
3. **Глобальные клавиши** — `RegisterHotKey` через CsWin32 **без окна**: с `hWnd = NULL` сообщения `WM_HOTKEY` приходят в очередь отдельного потока (`GetMessage`), остановка — `PostThreadMessage(WM_QUIT)`. По умолчанию `Ctrl+Alt+I` — поиск, `Ctrl+Alt+N` — добавление; сочетания задаются строкой (`HotKeyGesture.TryParse`), без модификатора не принимаются. `IsRegistered(id)` сообщает о конфликте с другой программой.
4. **Один экземпляр** — именованный `Mutex` + named pipe с `PipeOptions.CurrentUserOnly` (имена — на пользователя). Повторный запуск передаёт свои аргументы и завершается с кодом 0.
5. **Быстрый поиск** — окно без рамки (`WindowDecorations="None"`, Acrylic на Windows 11), создаётся один раз и скрывается: `Esc`, потеря фокуса или `Enter`.

| Что | Как | Результат |
|-----|-----|-----------|
| Парсер сочетаний, аргументы командной строки | Unit-тесты | ✅ |

| Запуск приложения, повторный запуск с `--quick-search` | Реальный запуск под Xvfb (X11) | ✅ окно открылось, второй процесс передал команду и завершился, появился быстрый поиск |

## Последствия

- Трей и горячие клавиши на Windows — главный риск фазы 4; чек-лист ручной проверки — в `docs/spikes/phase-0/checklist.md`.
- В Linux-окружении трей Avalonia требует D-Bus `StatusNotifierItem`; без него иконки нет, но приложение работает.
- Настройка сочетаний в UI и сообщение о конфликте (InfoBar) — фаза 4.
